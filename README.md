# ПАС · Такт 2 — объекты конкуренции и бутылочные горлышки

`index.html` — презентация, один самодостаточный файл. Шрифты вшиты
внутрь (base64), интернет не нужен. Открывается двойным кликом в любом браузере,
влезает на флешку.

`takt2-gamedev.pdf` — тот же материал на случай, если в аудитории нельзя
подключить ноутбук. 24 страницы, 16:9.

## Живая версия

**https://kom1sh.github.io/pas-takt2/**

Обновляется автоматически через ~30 секунд после пуша в `main`.

## Порядок слайдов

Обложка → что такое геймдев → понятие объекта конкуренции → раздел 01 → карта
уровней → восемь этажей по одному слайду (ИС, концепт, движки, аутсорс,
разработка, издание, платформы, витрины) → «мало игроков — ещё не горлышко» →
проверка «соседние этажи не совпадают» → раздел 02 → понятие горлышка → тест
отказом → витрина как класс → три проверенных случая → скрытые горлышки →
открытый вопрос → источники всех чисел → понятия такта.

Логотипы аутсорс-студий (Virtuos, Room 8, Keywords, JALI, Wolf3D) — растровые,
вшиты в `src/raster.json` как WebP; остальные знаки — Simple Icons в `src/sprite.html`.

## Заголовки

Заголовок слайда называет тему и объект конкуренции этажа — «Концепт: снижение
риска до вложений», «Разработка: игровой опыт». Примеры и формулы живут в
карточках и лиде, не в заголовке.

## Редактируемый .pptx

`takt2-gamedev.pptx` — прототип для правок командой, 27 слайдов в том же стиле,
но с доработками по пленару 04.09: новые объекты на этажах 02/03/04/05/07/08,
определение витрины, цепочка удержания, пайплайн выхода на витрину с комиссиями,
измеримость объекта, Valve и Epic на нескольких этажах, Cyberpunk на каждом этаже.

Собирается скриптом: `PPTX_ICONS=src/pptx-icons python3 src/build_pptx.py`
(нужен `python-pptx`, иконки лежат в `src/pptx-icons`). Шрифт — Onest; если он не
установлен, PowerPoint и Keynote подставят системный — поставьте Onest с Google Fonts,
чтобы совпало с HTML-версией. Все фигуры и тексты — обычные объекты, редактируются.

HTML-дека и .pptx пока расходятся по содержанию: в HTML — версия до пленара,
в .pptx — после. Какую сделать основной, решается командой.

## Проверка вёрстки

**Обязательный шаг перед любой отдачей деки.**

    python3 src/qa.py

Поднимает сервер, прогоняет все слайды и проверяет: пустые слайды, выход
за края кадра, обрезанный текст (`scrollHeight > clientHeight`) и элементы,
вылезшие за свою карточку. Контактный лист с пометками — `/tmp/deck-qa/sheet.png`.
Выходной код 1, если найдены дефекты.

Проверка геометрии живёт прямо в деке: `index.html?qa=1` запускает её в браузере
и кладёт результат в `document.title`. Скриншот на глаз такие дефекты не ловит —
именно так были пропущены съехавшие иконки и обрезанная таблица источников.

## Как править

Содержание деки живёт в одном месте — `src/content.py`. Оттуда собираются
**и сайт, и .pptx**, поэтому они больше не расходятся.

    src/content.py       — карта уровней, слайды этажей, тексты, источники
    src/deck.tpl.html    — оформление сайта и логика листания
    src/build_pptx.py    — оформление .pptx

    python3 src/make_slides.py && python3 src/build.py      # сайт
    PPTX_ICONS=src/pptx-icons python3 src/build_pptx.py     # презентация
    git add -A && git commit -m "..." && git push

27 слайдов в обеих сборках, нумерация совпадает.

Фотографий в деке нет намеренно: единственная уместная здесь фотография —
скриншоты игр, а это чужие права. Роль якорных картинок играют логотипы,
крупные числа и схема-воронка.
