# ПАС · Такт 2 — объекты конкуренции и бутылочные горлышки

`index.html` — презентация, один самодостаточный файл. Шрифты вшиты
внутрь (base64), интернет не нужен. Открывается двойным кликом в любом браузере,
влезает на флешку.

`takt2-gamedev.pdf` — тот же материал на случай, если в аудитории нельзя
подключить ноутбук. 24 страницы, 16:9.

## Живая версия

**https://kom1sh.github.io/pas-takt2/**

Обновляется автоматически через ~30 секунд после пуша в `main`.

## Порядок слайдов

Обложка → что такое геймдев → понятие объекта конкуренции → раздел 01 → карта
уровней → восемь этажей по одному слайду (ИС, концепт, движки, аутсорс,
разработка, издание, платформы, витрины) → «мало игроков — ещё не горлышко» →
проверка «соседние этажи не совпадают» → раздел 02 → понятие горлышка → тест
отказом → витрина как класс → три проверенных случая → скрытые горлышки →
открытый вопрос → источники всех чисел → понятия такта.

Логотипы аутсорс-студий (Virtuos, Room 8, Keywords, JALI, Wolf3D) — растровые,
вшиты в `src/raster.json` как WebP; остальные знаки — Simple Icons в `src/sprite.html`.

## Как править

Собранный `index.html` руками не трогаем — он генерируется.

    # 1. правим содержание
    src/slides.html      — текст слайдов
    src/deck.tpl.html    — оформление и логика листания

    # 2. пересобираем
    python3 src/build.py

    # 3. выкладываем
    git add -A && git commit -m "..." && git push

`src/fonts.css` — Oswald и Geologica, вшитые в base64. Трогать не нужно,
он существует, чтобы дека работала без интернета.

Проверить локально перед пушем: просто открыть `index.html` в браузере.
Пересобрать PDF:

    python3 -m http.server 8000 &
    "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
      --headless=new --no-pdf-header-footer --virtual-time-budget=8000 \
      --print-to-pdf=takt2-gamedev.pdf http://127.0.0.1:8000/index.html

## Управление

| Клавиша | Действие |
|---|---|
| `→` `Space` `PageDown` | следующий слайд |
| `←` `PageUp` | предыдущий |
| `Home` / `End` | первый / последний |
| `O` | сетка всех слайдов, клик — переход |
| `F` | полный экран |

Клик в правые ¾ экрана — вперёд, в левую ¼ — назад. На тачскрине — свайп.
Ссылка вида `...html#7` открывает сразу седьмой слайд.

## Как читать оформление

Цвет несёт смысл, а не украшает:

- **жёлтый** — только объект конкуренции;
- **голубой** — структура: уровни, разметка, понятия;
- **красный** — только горлышко и то, что отказывает.

Слева — шкала этажей. На слайде про конкретный этаж соответствующее деление
подсвечивается; восьмое (горлышко) — красным.

## Фактура

Все числа деки собраны на слайде «Откуда взяты числа» со ссылками. Три правки
после сверки с источниками:

- Godot 11% ничем не подтверждался — заменён на 8–10% релизов в Steam (Q1 2026);
  «три движка — 83%» стало «два — у 72% студий» (Unreal 42% + Unity 30%, опрос GDC 2026).
- Аутсорс $14,7 млрд не встречается ни в одном отчёте; оценки на 2024–25 год — $4–9 млрд.
  На слайде «около $9 млрд» со ссылкой на verifiedmarketreports.com.
- «Шесть ворот на весь мир» снято как слишком категоричное. Везде — «несколько крупных
  витрин», а цифра 6 на слайде обоснования заменена на GOG 2–3% (levvvel.com).

## Логотипы

Иконки — [Simple Icons](https://simpleicons.org/), лицензия CC0, вшиты в
`src/sprite.html` как inline SVG и раскрашены в фирменные цвета из того же набора.
Белые и чёрные фирменные цвета заменены на чернила: на белой плитке белое
невидимо. На чёрной строке-горлышке знаки инвертируются в кремовый.

Логотипы описаны данными в `src/make_slides.py` (словари `BRAND` и `NAME`),
а не разметкой — добавить новый бренд можно одной строкой, если его глиф есть
в спрайте.

## Как править

    src/make_slides.py   — содержание слайдов и логотипы
    src/deck.tpl.html    — оформление и логика листания
    python3 src/make_slides.py && python3 src/build.py
    git add -A && git commit -m "..." && git push

Фотографий в деке нет намеренно: единственная уместная здесь фотография —
скриншоты игр, а это чужие права. Роль якорных картинок играют логотипы,
крупные числа и схема-воронка.
